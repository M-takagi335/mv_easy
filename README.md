# MV Easy

テキストや図形にアニメーションを重ねて、文字PV・MVを作る日本語のエディターです。

## 起動

Node.js 22.18 以降で実行してください。

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL をブラウザーで開きます。

## 操作

- 「＋追加」からテキスト・四角形・円を追加し、右のプロパティで位置、サイズ、回転、色を調整します。
- レイヤーを選んで左のテンプレートを押すと、再生位置付近にアニメーションが追加されます。同じレイヤーに複数追加できます。
- レイヤー名の左にある矢印でアニメーションを展開します。バーの中央をドラッグすると移動し、左右の端をドラッグすると長さを変えられます。
- Tab キーでバーの開始端または終了端にフォーカスし、Alt＋←／→で 0.1 秒ずつ動かします。
- 時間目盛りやトラックの空いているところをクリックすると、その位置から確認できます。

起動時は 15 秒のサンプルが開きます。編集中の内容はページを開いている間、メモリに保持されます。

## 開発

```sh
npm test
npm run build
```

テンプレートと調整項目は `src/templates.ts`、時刻からオブジェクトの表示状態を求める処理は `src/animation.ts` にあります。
